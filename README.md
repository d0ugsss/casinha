# Nossa Casinha

Joguinho de combinar 3 e decorar a nossa casa, feito pro dodô e a tata.

A casa inteira: 8 cômodos em 3D (quintal, sala, cozinha, nosso quarto, banheiro, escritório, quarto de hóspedes e área gourmet), 64 fases de combinar 3, 13 desafios com a família (3 deles são os URGENTES da Margarida) e a festa final.

## Como jogar no iPhone
Abra o link do GitHub Pages no Safari e toque em Compartilhar → "Adicionar à Tela de Início" pra ele abrir em tela cheia.

## Rodando no computador
Qualquer servidor estático serve, por exemplo:

```
python3 -m http.server 8000
```

e abra http://localhost:8000. Para testar com atalhos, use `?dev=1` (ou `#dev`) no fim do endereço.

Créditos: three.js (MIT); móveis do Furniture Kit da Kenney (CC0, assets/kit); músicas compostas pro jogo e tocadas com o soundfont GeneralUser GS (S. Christian Collins).
